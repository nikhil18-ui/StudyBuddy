# 📚 StudyBuddy – Simple Study Planner

StudyBuddy is a simple student study planner website that helps students manage their daily study tasks.

## ✨ Features

- Add new study tasks
- View all study tasks
- Mark tasks as completed
- Delete tasks
- Save tasks using Local Storage
- Simple and beginner-friendly design

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Local Storage

## 📂 Project Structure

```text
studybuddy/
├── index.html
├── style.css
└── script.js
```

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Start adding your study tasks.

## 🎯 Project Purpose

This project was created to practice basic web development concepts, including HTML elements, CSS styling, JavaScript functions, arrays, click events and Local Storage.
